# 视频换皮 Skill 制作与校验

用户指定维护目录：`E:/MegoNew/.agents/skills/market/`。

当前入口：video-reskin（工程内查阅）。技能包含主流程、角色与动作连续性、生成任务与成片交付、换皮计划模板、中文调用元数据共5个文件。具体影片、角色母版、任务编号、媒体和旧批次未复制进技能。

## 采用方法

预读目标工作区 `AGENTS.md`、`skill-authoring`、`market`入口与共享纠错账，命中维护入口／历史快照区分、UTF-8中文元数据、实测与听审边界。参考了既有UA制作、影视角色与资产换皮入口的职责，新增技能聚焦已有原片的角色／主题替换与返修，不接管从零创意、纯多语言本地化或游戏内资产批量换皮。

正文覆盖角色映射、完整原片和HUD残留盘点、首帧缺陷先修、工具／天气／开合因果、供应商能力与免费范围核实、原任务恢复、真实玩法来源、可编辑剪辑、实际文件播放及分别记录声音和编辑器展示状态。

文档场景推演检查了：继续已批准的整片与原生成任务；首帧含不应出现的雨线或火花；动物居民在抱起后衣装与物种漂移；关闭玻璃被穿过；旧头像在源片缩放后露出；原片玩法与目标产品实录混淆；文件完成但听感／原生面板仍不可验证。此推演不是一次新视频生产或用户采用验收，本轮未调用图像／视频供应商。
