# 视频多语言适配工具 · 商业化小组试用

已有广告视频可以沿用原分镜，通过本地化 Agent 和 ad-creative-localization Skill 自动替换画面文字、图片、对白与配音，部分镜头可随新对白调整口型。

支持简体中文、繁体中文、西班牙语、德语、阿拉伯语、韩语、印尼语和马来语。每支视频按所需语言输出，精细口型和母语观感仍由人工审核。

交付物为 AdLocalizationKit 1.1.0 部署包、配套 Agent 和 Skill。已交商业化小组试用，等待反馈。工程记录中的 5 项部署检查已通过，发布回读核对了部署包和 148 项文件指纹。
