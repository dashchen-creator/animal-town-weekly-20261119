# v96 恢复棋盘整理

旧版 v94/v95 的整理入口曾通过内网签名补丁发布。对应功能只存在于旧补丁的构建副本。SVN 主线及由它导出的 v96 首包和累计补丁缺少按钮和整理命令。

在 v96 r400 数值基线上恢复 Sort 底栏入口、确认弹窗和一次存档提交。保存既有棋子记录与发射器库存，锁格和冰封格留在原位置。选中棋子或底栏对白显示时暂时隐藏入口，清除选择或对白结束后恢复。工作副本同步加入两个脚本的增量，保留已有订单改动。

已发布的内网补丁为 r00000007。原 APK 的媒体和 Flambé v4 配置继续使用已验基线。通过公开给内网 APK 的实际发布地址完整下载核对摘要，并在登录前挂载。

| 验证 | 结果 |
| --- | --- |
| v96 APK 游戏载荷 1080×1620，原 v3 车站存档 | 实点 84 项通过，含入口、选中与取消选中、确认和取消以及读回棋盘。 |
| 同一 APK 游戏载荷 1080×2340，原 v4 客栈存档 | 实点 77 项通过，含底栏对白结束恢复入口、整理前后棋子与资源对照。 |
| 独立存档失败夹具 | 写入失败保持原状态。重试只保存一次，重复整理已排序棋盘无新增写入。 |
| 真实内网源 | r00000007 登录前生效，v4 首发箱仍为 24 库存且首六发顺序保持。 |

证据原件和发布回执在 LocalOnly/android-lan-r396-20261125/sort-restoration-hot。Android 真机待复验。

Android 构建在导出前执行整理探针，在验包时核对棋盘界面和会话脚本的导出条目。探针对 v96 原 APK 加缺少整理的 r00000005 明确报错，对同一 APK 加 r00000007 通过。棋盘热更沿用此探针与真实操作复验。 出包规则（工程内查阅）
