# 离线 HTML 棋盘合成卡顿修复 · 2026-11-16

用户反馈局内合成有明显卡顿，并确认发生在离线 HTML 浏览器版。本轮修复正式 client，生成本地离线 HTML；不发布、不提交、不操作原工程与原工程 MCP。

## 原因与修复

1. `StorySession.commit → changed → StoryHomeScreen._render → CollectionSession.claimable_count` 每次棋盘保存都重算全套图鉴的套装/部件关系，即使小镇被棋盘覆盖。原统计中位耗时约 15.16ms。将不随存档变化的关系按 `StoryCatalog` 实例缓存；所有权、发现状态、领取资格继续读取当前存档。返回数组仍为调用方独立副本。改后约 1.14ms，小镇整页刷新从 16.94ms 降到 2.61ms。
2. 拖拽结束中命令提交同步触发棋盘 `_render`，随后结束处理再次 `_render`；产出也有同类重复。加入仅限本次同步 drop 处理的刷新合并，业务提交、选中状态、动画登记完成后，在输入返回前统一刷新。未改提交时机、失败事务或引导事件。
3. 合成光圈、星光、产出飞行图标直接挂到整个棋盘 form。`FGUIComponent._add_child_node → refresh_color_filter(node,true)` 因此重复遍历整个棋盘与订单树。增加不接收输入的 `BoardFeedback` 容器，临时视觉节点只触发该小子树更新。容器与 form 共用原点，resize 同步尺寸；预览仍在 ghost 下方，原 tween/曲线/坐标/素材保留，关闭随 form 释放。

最终仅改 `merge_board_screen.gd`、`story_catalog.gd`、`collection_session.gd`。采样时临时修改过的 `story_session.gd`、`story_home_screen.gd`、`board_art.gd` 已逐字节恢复，SHA 对照见 summary。原有工作副本改动保持。
