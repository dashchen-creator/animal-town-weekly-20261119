# MegoNative

Windows-first native infrastructure for the Godot client, copied from the authorized RR mpnative source. Gameplay remains GDScript. This library preserves original C++ HTTPS authentication, device-protected encrypted LevelDB, local atomic records/outbox, background cloud synchronization, conflict handling and reliable reports.

Use the [AnimalTown source build](/animal-town-weekly-20261119/files/554d89e5340e2c660d712734.md) for the Windows GDExtension and native tests. Build outputs and test data live under AnimalTownClient's `LocalOnly`. PORTING.md（原始引用未随本次网页发布） records the upstream port and its dependencies.

`../MegoProto` is the shared protocol source and generated C++ tree. `godot/` contains the GDExtension, the protobuf reflection codec, and the Godot adapter for AnimalTown's online candidate.

The retained source has one documented recovery correction: explicitly keeping a never-synced new player may replay its complete original business outbox against the same verified empty cloud baseline. Atomic native proofs account for private-only save revisions before the first cloud acknowledgement; they never enter the network outbox and are cleared when a cloud baseline exists. Different baselines, missing/invalid proofs and incomplete chains retain the conflict guard. It never replaces the operation chain with a snapshot. The separate local presentation schema contains typed reward receipts and the int64 guide visual handoff; actual guide progress uses the original onboarding domain.

Upstream Windows verification is recorded in BUILD_VERIFICATION.md（原始引用未随本次网页发布）. AnimalTown verification is recorded in [server capabilities](/animal-town-weekly-20261119/files/fa3a1402cbff8aa724492003.md).
